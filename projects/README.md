# projects

每个项目是本目录下的**一个文件**，不是一套子目录。

规则全文见 [../RULES.md](../RULES.md)。

## 约定

- 路径：`projects/<name>.md`
- `<name>` 使用 kebab-case（小写字母、数字、连字符）
- 命名示例：`chenzhou-new-year.md` → `projects/chenzhou-new-year.md`

上面的文件名只说明命名方式。本目录里还没有真实项目；不要为了凑示例而新建虚构项目。

## 新项目文件可以这样起稿

把标题和正文换成真实内容后再提交：

```markdown
# 项目名称

## 目的

一句话说明这个项目做什么。

## 状态

进行中 / 已完成 / 暂停

## 记录

- 日期：发生了什么
```

## 不要做的事

- 不要为一个项目再建子文件夹或拆成多个文件。
- 不要在仓库根目录随意加文件。
- 不要写入密钥、令牌或其他秘密。

若确实需要多文件或子目录，先由 Morgan 批准。

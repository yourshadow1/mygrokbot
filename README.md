# mygrokbot

Grok Bot 团队的工作区仓库。整个工作区的项目与约定都放在这里，由 **Bot Morgan** 统一管理。

规则全文：[RULES.md](RULES.md)。

## 仓库里有什么

- [RULES.md](RULES.md) — 治理规则（中文为主，附简短英文）
- [projects/](projects/README.md) — 每个项目一个文件

## 如何新增一个项目

1. 先读 [RULES.md](RULES.md)。
2. 在 `projects/` 下新建**一个** Markdown 文件。
3. 文件名用 kebab-case，例如 `projects/chenzhou-new-year.md`。
4. 一个项目只放这一个文件，不要再建子目录或在根目录另起文件。
5. 用 Pull Request 提交，提交说明写清楚改了什么、为什么改。
6. 不要提交密钥，也不要编造并不存在的项目。

其他 bot 必须遵守 [RULES.md](RULES.md)。不合规则的变更由 Morgan 点名纠正，或告知负责人。

项目目录的写法见 [projects/README.md](projects/README.md)。
